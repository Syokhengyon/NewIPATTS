# IPA 讀音合成 — v1

把 IPA 轉寫**真正唸出來**的離線工具。純靜態網頁 + 本地 Node 服務，不依賴任何外部站點。

語音引擎是 **espeak-ng**（Emscripten 構建，跑在 Web Worker 裏）；
IPA → espeak 音素名的對照表以**口口聲聲站點作者的那張表**爲基準，
在此之上做了有限的增補與修正（每一條都註明依據，見第五節）。

```
┌──────────────────────────────────────────────────────────┐
│  三種輸入 → IPA  →  espeak 音素名  →  espeak-ng  →  WAV  │
│  ─────────────                                           │
│  ① 切韻推導器（貼 JS 方案）                              │
│  ② 字表（字 → IPA）                                      │
│  ③ 直接輸入 IPA                                          │
└──────────────────────────────────────────────────────────┘
```

## 一、快速開始

### 1.1 Windows：雙擊 `start.bat`

把專案解壓到硬碟上的資料夾（**不要在壓縮包裏直接雙擊**），然後雙擊根目錄的 **`start.bat`**。
它會自動做完這四件事：

| 步驟 | 做什麼 |
|---|---|
| ① 檢查 Node.js | 沒裝或低於 18 → 提示原因並打開下載頁 |
| ② 裝依賴 | 首次運行自動 `npm install`（約 10–60 秒）；失敗會改用專案內的 `.npm-cache` 再試一次 |
| ③ 挑端口 | 預設 8981；被別的程式佔用就自動往後找；若 8981 上**已經是本服務**，只開瀏覽器、不重複啟動 |
| ④ 起服務 | 等 `serve.mjs` 真的能回應 HTTP，才自動打開瀏覽器 |

**關掉那個窗口就是停止服務**。（按 Ctrl+C 也行，只是 cmd 會再問一句
`終止批處理作業 (Y/N)?`，答 `Y` 即可 —— 這是 `cmd.exe` 對批次檔的固有行爲。）

```bat
start.bat                  :: 預設端口，自動開瀏覽器
start.bat --port 9000      :: 指定端口
start.bat --no-open        :: 不自動開瀏覽器
start.bat --install        :: 強制重新 npm install
start.bat --help           :: 全部選項
```

想要桌面捷徑：右鍵 `start.bat` → 傳送到 → 桌面（建立捷徑），再改圖示即可；
捷徑不管從哪個目錄點都會正確進入專案目錄。

> **爲什麼 `start.bat` 裏一個中文都沒有**：cmd.exe 用當前代碼頁解讀 `.bat`，
> 在 936／65001 之間切換時非 ASCII 字元會亂碼，甚至讓 `if` 區塊解析錯。
> 所以 `.bat` 只管找 `node.exe`、檢查版本、轉交，**所有中文提示都由
> `tools/start-web.mjs` 輸出** —— Node 在 Windows 上是以 Unicode 寫控制台
> （`WriteConsoleW`），跟 `chcp` 無關，任何代碼頁都不會亂碼。

也可以不經過 `.bat`：`npm start` 就等於 `node tools/start-web.mjs`。

### 1.2 手動啟動（macOS / Linux，或想看完整輸出）

在專案根目錄（與 `package.json` 同一層）：

```bash
npm install                 # 首次
npm run serve               # 起服務（必須）
```

然後打開 **http://127.0.0.1:8981/**

> **必須走 HTTP**，不能直接雙擊 `.html` —— 頁面用了 ES module、
> `fetch` 和 Web Worker，`file://` 下會被瀏覽器攔掉。

### 三個頁面

| 路徑 | 頁面 | 用途 |
|---|---|---|
| **`/`** | 切韻推導 | **主界面**。貼入推導方案 → 輸入漢字 → 逐字推導並朗讀 |
| `/ipa` | IPA 直輸 / 字表 | 模式二（字表）與模式三（直接輸入 IPA） |
| `/chart` | IPA 逐音素驗證表 | 點格子聽單個音素，用來人耳驗證對照表 |

| Node.js | ≥ 18 | 只用作本地靜態服務器 |
| 瀏覽器 | 現代瀏覽器 | 需要 Web Audio + Web Worker + WASM |


> `npm install --cache ./.npm-cache`

### 隨包自帶（不需額外下載）

| 路徑 | 大小 | 說明 |
|---|---|---|
| `engine/espeakng.js` | 2 KB | espeak-ng 的 Worker 封裝 |
| `engine/espeakng.worker.js` | 832 KB | Emscripten 構建的引擎本體 |
| `engine/espeakng.worker.data` | 6.5 MB | 音素資料（已烘焙 `wide80` 嗓音變體） |

## 四、用法

### 4.1 模式一：切韻推導（`/`）

#### 兩個專門目錄

界面上有兩個下拉框，直接列出這兩個目錄裏的檔案。
**只從這兩個目錄讀、也只往這兩個目錄寫** —— 往目錄裏丟檔案，刷新頁面就出現在下拉框裏；
在頁面上改完按「儲存」**直接覆蓋原檔**：

| 目錄 | 放什麼 | 界面上 |
|---|---|---|
| **`texts/`** | 推導文本（`.txt` / `.md`） | 「文章」區的下拉框 + 儲存／另存新檔 |
| **`derivers/`** | 推導器腳本（`.js` / `.txt` / `.mjs`） | 「自定推導方案」區的下拉框 + 儲存／另存新檔 |

載入某個檔案後，下方會顯示「已綁定檔案：**千字文.txt**（「儲存」會直接覆蓋它）」；
未綁定時按「儲存」會問檔名。

實現是 serve.mjs 的三個接口：

| 接口 | 作用 |
|---|---|
| `GET /api/texts`、`GET /api/derivers` | 列出目錄內容 |
| `POST /api/save` | 寫入 `{dir, name, content}`，**只認這兩個目錄** |

保存接口的限制（都有測試守着）：

* 目錄名白名單 —— `dir` 只能是 `texts` 或 `derivers`
* 檔名拒絕路徑分隔符、`..`、開頭為點
* 解析後再確認最終路徑確實落在目標目錄內
* 副檔名白名單；內容上限 4 MB

> **不含存檔的匯入／匯出**：早先有「匯入 txt／存成 txt（下載）」兩個按鈕，
> 已移除 —— 改檔案請直接放進 `texts/`，改完就在頁面上按「儲存」。

#### 貼入推導方案

推導方案是**函數體**，可用的自由變數有**四個**：

```js
new Function("TshetUinh", "選項", "音韻地位", "字頭", 方案代碼)
```

| 變數 | 說明 |
|---|---|
| `TshetUinh` | 整個資料庫 |
| `選項` | 方案自己宣告的設定項，預設 `{}` |
| `音韻地位` | 音韻地位實例，可用 `屬於` / `調整` / `描述` 等 |
| `字頭` | 當前漢字，預設 `null` |

**缺任何一個，用到它的方案就會整個拋錯** —— 例如只傳 `音韻地位` 時，
用 `字頭` 做例外處理的方案會拋「字頭 is not defined」。

#### 宣告設定項

方案用「**`音韻地位` 爲 null 時返回設定項列表**」宣告介面：

```js
if (!音韻地位) return [
  ['模式', '標準', {
    text: '推導模式',
    options: [{ value: '標準', text: '標準' }, { value: '簡略', text: '簡略' }],
    description: '選擇推導的詳細程度',
  }],
  ['大寫', false, { text: '轉大寫' }],
];
```

頁面自動渲染成下拉框 / 複選框 / 數字框，並**按方案分別記憶**。

#### 括號注音（固定讀音）

在漢字後面用括號寫出音韻地位，該字讀音即被**固定**：

```
賀新郎 同父(幫三虞上)見(見開四先去)和再用韻答之 （辛棄疾）
事(崇開三之去)無兩樣(以開三陽去)人心別(並三B仙入)。
```

* 括號內容只要是**合法的音韻地位**就當注音 —— 判斷方式是實際 `from描述` 一次，
  **不是正則**，所以 `（辛棄疾）` 這種不會被誤認。
* 半角 `()` 與全角 `（）` 都支持。
* **省了「類」會自動補全**：`幫三虞上` → `幫三C虞上`。
  補全結果寫進日誌，多個候選都能解析時會提醒有歧義。

#### 借字：`說<悦>`

在某字後用角括號標出**另一個字**，表示「直接用那個字的音韻地位」：

```
説<悦>          用「悦」的音韻地位（以合三仙入）來讀「説」
```

* 半角 `<>`（`<` U+003C / `>` U+003E）與全角 `〈〉` 都支持，內容必須是**單個漢字**。
* 這樣指定的字**標紅**（和「與廣韻不合」同色）。
* 若被借的字有多個音韻地位，**列表項同樣可選** —— 選了就寫回成
  `字(音韻地位)` 的括號形式（變成綠色），角括號隨之移除。
* 被借的字查不到音韻地位時，本字標紅並在日誌和懸停提示裏說明。
* **字頭傳的是本字**（説），不是被借的字 —— 要發音、要顯示的都是本字，
  借來的只是音韻地位。方案裏按 `字頭` 做的例外因此仍作用於本字。

#### 標點與分段

**標點保留爲停頓**，不再一律濾掉。（早先爲了不讓 `（辛棄疾）` 的括號變成字格，
把所有非漢字都濾了，結果逗號句號一起消失，斷句變得莫名其妙 —— 已修。）

| 輸入 | 效果 |
|---|---|
| **行內空格** | **微停頓**（約 30–60 ms，比逗號短） |
| `，` `,` `、` | 短停頓（約 120 ms） |
| `。` `！` `？` `；` `：` | 換行 + 長停頓（約 300 ms） |
| **空行** | **分段**（約 500 ms 停頓） |
| `（）` `「」` `《》` 等 | 丟棄（括號本身不佔字格） |

空格作停頓有兩個**例外**，都不算：

* **行首縮排** —— 前面沒有字，只是排版
* **行尾殘留** —— 後面就是換行或文末

多個空格合併成**一個**微停頓；半角空格、製表符、全角空格（U+3000）一視同仁。
微停頓的上限是 60 ms，**不隨「字間隔」滑條無限變大** —— 否則它就不再「比逗號短」了。

三級停頓在結果區也是三種大小的小點（微 3px、短 5px、長 13px 長條）。

> **音長補償也管停頓邊界。** 引擎把帶塞音尾的音節壓到只有 61–62%
> （`ik` 74 ms、`ɑk` 95 ms，而 `ɑ` 是 218 ms），所以有「補償」滑條：
> `gap = 補償 × (目標週期 − 已用時長)`,`已用時長` 含**已有的停頓時長**。
> 這樣「字接字」和「字接空格/標點」走同一條公式 ——
> 早期版本只處理前者，短音節後面接一個 40 ms 的空格停頓就補不到，
> 聽感像被吞掉（回歸測試：`tools/test-stop-gap.mjs`）。
> 標點本身的長度只會被**補足**、不會被縮短，所以句號的 320 ms 不動。

**分段**後右欄把每段框起來，各帶一個 **▶ 只唸這段** 按鈕；
工具列也會出現「段落」下拉框，可只朗讀其中任一段：

```
段落 1  [▶ 只唸這段]
  天地玄黃，宇宙洪荒。
段落 2  [▶ 只唸這段]
  日月盈昃，辰宿列張。
```

按 ▶ 的規則：**內容或設定與上次合成一致才重播，否則重新合成** ——
不然「只唸過第 2 段」之後再按 ▶，會誤以爲手上是全文。

#### 結果區的五種顏色

| 顏色 | 含義 |
|---|---|
| 🟢 **綠** | **源文本裏有括號註明**（`字(音韻地位)`），讀音已固定，且與廣韻相合 |
| 🔴 **紅** | **借字**（`字<他字>`）；**或**三張表都查不到；**或**括號所註與廣韻**完全不合** |
| 🟡 **黃** | 不在廣韻，但可由**補充字表**或**異體字表**類推 |
| 🔵 **藍** | 多音字（右上角角標是讀音數，點擊切換） |
| ⚪ **灰** | 單一讀音 |

鼠標懸停會說明來源：

```
窗  不在《廣韻》字表，由補充字表類推：初二江平
国  不在《廣韻》，經異體字「國」類推：見合一登入
天  ✗ 括號註明 幫三C虞上，但《廣韻》作 透開四先平 —— 兩者不合
```

#### 改讀音 → 寫回原文

**點任何字都會彈出它的全部音韻地位**（灰色單音字也一樣），每項帶**釋義**：

```
┌──────────────────────────────────────────────────────────────────┐
│ 「列」2 個音韻地位                                                  │
│   ʈʉɵ⁵³  知合三虞平　陟輸   殊殺字從歹歹五割切            ← 可點     │
│   ɭiet²  來開三仙入　良辥   行次也位序也又陳也布也說文作𠛱…  ← 可點   │
│   試聽全部（依序）                                                  │
│ ──────────────────────────────────────────────────────────────── │
│ 自訂音韻地位 [幫三C虞上          ] [確定]                           │
└──────────────────────────────────────────────────────────────────┘
```

釋義**來自廣韻原文**（最長 120 字，兩行截斷，鼠標懸停看全文）；
類推查到的字也帶釋義（例如 `窗` → 「原下作怱，注説文作窗」）。

**只有多於一個音韻地位時，列表項纔可點選** —— 單一讀音的項樣式變淡、不可點，
下面會註明「唯一讀音，無需選擇」。這樣「能點」本身就傳達了「這裏有得選」。

**綠色字也列出廣韻的其他讀音**，所以想換直接點，不必手打。

任何改動都**寫回源文本**（在該字後插入或替換 `(音韻地位)`）：

```
改之前：  列令行天
改之後：  列(來開三仙入)令行天(幫三C虞上)
            └ 綠，已固定       └ 紅，與廣韻不合
```

**「綠色」的真正含義就是「源文本裏有括號」** —— 所以改完立刻變綠、
再改替換原括號（不疊加）、而且**按「儲存」覆蓋回 `texts/` 的原檔**，
下次載入能完整復現。

輸入非法音韻地位不會寫入，彈窗保持打開並提示；與廣韻不合時會先問一次再寫。

#### 關於「類推」

《廣韻》字表收字有限（`窗` 就查不到，只有 `窻`）。本站做三層查找：

1. **廣韻**（`tshet-uinh` 內建）
2. **補充字表** —— 從站點 WASM 提取的另一張表，收字更廣，直接帶音韻地位
3. **異體字表** —— 找同組異體字再查上面兩張表

第 2、3 層查到的都標黃色。**簡化字也走第 3 層**：

```
国 → 囯 圀 國     汉 → 漢     说 → 說 説     东 → 東
```

### 4.2 模式二：字表（`/ipa`）

三種格式，自動識別：

```
山 ʂæn⁵³                              # 文本，每行一條
{ "山": "ʂæn⁵³" }                     # JSON 對象
[ { "字": "山", "ipa": "ʂæn⁵³" } ]    # JSON 數組
```

### 4.3 模式三：直接輸入 IPA（`/ipa`）

輸入 `tʰen⁵³ ɖɨw²¹² ʈʂɨk⁵` 這樣的串直接合成。
**這是驗證對照表的主要手段** —— 表裏沒有的符號會被丟棄並在日誌裏列出。

### 4.5 頁面選項

| 選項 | 默認 | 說明 |
|---|---|---|
| 嗓音 | `wide80` | 音域加寬的變體。另有原版 `ipa` |
| 音調 | 40 | 對應 espeak 的 `pitch` |
| 語速 | 140 | |
| 字間隔 | 45 ms | 逐字合成後拼接時的靜音長度 |
| 零聲母 | 前加喉塞 ʔ | 影母等零聲母字的補償方式，可選加長 / 不補償 |
| 三位調降速 | **不降速** | 見下 |

**三位調降速默認關閉。** 實測 espeak 給每個音節**固定時長**，二位調與三位調本來就等長：

```
速率 140:   31 = 224ms   313 = 228ms   (1.02×)
速率 224:   31 = 119ms   313 = 118ms   (0.99×)
```

降速（×0.6）會讓音節變成 1.67 倍長，只是爲了看清輪廓 —— 需要時再開。

**但三值調本身經常走不出輪廓。** 16 種三值調形逐個實測（`ta` 語境、速率 140、自相關估 F0）：

```
能讀出輪廓（5 種）：223  213  212  231  445
壓成平調（10 種）：224  222  214  234  132  242  354  453  334  543
（131 有聲幀太少，測不出）
```

例：`224` 的軌跡是 `0 0 0 0 0 0 0`（平），`2` 之後那一跳根本到不了；
而 `213` 是 `0 −1 −1 −1 0 1`（先降後升）✓。

救不回來：拉長元音（`ta:224` 801ms、`ta::224` 860ms）仍平，降速到 100/70 也仍平。
所以**三值調能不用就不用** —— 例如 `²²⁴` 應寫成 `²⁴`
（`derivers/high_tang.txt` 的「全濁上歸去」就是這樣把濁去壓成 `²⁴`）。
真要保留三值調，只能靠後期重畫 F0（`src/tones.mjs` 已備好五度值 → 半音的映射）。

## 五、對照表：做了什麼、沒做什麼

### 基準

`reference/author-ipa-to-ascii.py` 是站點作者的原表（247 條），
`IPA_TO_ESPEAK_AUTHOR` **逐字照錄，未作任何改動**。

合併順序：**增補表 → 作者表 → 覆蓋表**（後者勝）。

### 增補（19 條）

作者表漏掉、但引擎確實支持的音。逐條註明來源，其中 11 條依據是**人耳試聽**：

```
ɭ→l.   ɬ→l#   ʎ→l^   t̪→t[   d̪→d[   n̪→n[
ʏ→Y    ʕ→?\   ħ→H    ɸ→f[   ɱ→m[   ⱱ→v[   ɾ→r    ɮ→l[   ʟ→L[
θ→s[   ð→z[   ʰ→h   ̃→~
```

> `ç`（`ç→C`）與 `ʝ`（`ʝ→J^`）原本也在這張表，現在都改由覆蓋表接手：
> `C` 在裁剪過的資料裏只有 −48 dB，`J^` 雖然就是官方 `ipa ʝ`，但為了跟 `ç→xj` 清濁配套，
> `ʝ` 也改用 `Qj`。

### 覆蓋（28 條）

作者取值實測失效、或有更合適寫法的項。**每一條都附依據**：

| IPA | 取值 | 依據 |
|---|---|---|
| `ʱ` 系列 | `h.`（＝ɦ） | 使用者指定。作者原表把濁送氣當清音 `h`，他自己標了 FIXME |
| `ʀ` | `r"` | 作者用 `R`，實測被忽略 |
| `a` `ɑ` `ɒ` | `A.` `a` `A` | 使用者反覆試聽的最終判定。`phoneme a` 是英語 TRAP 元音 [æ]（phsource 自己註明 `// trap`），比漢語 [a] 前得多；作者原表 a→a、ɑ→A、ɒ→A.，先對調 ɑ/ɒ，再把 a/ɑ 對調。A / A. 在本包 phsource 子集裏沒有定義，音值只能靠聽感定 |
| `ɣ` | `g"` | 官方 `phoneme Q { vcd vel frc }` 雖然才是濁軟顎擦音，但 `Q` 在這份裁剪過的資料裏只剩低頻濁音（重心 480 Hz、<500 Hz 佔 56%、1.5–3.5 kHz 只有 2%），聽着像帶 j 的滑音。改用 `g"`（重心 752 Hz、約 120 ms 摩擦段）後聽感正常 |
| `ʝ` | `Qj` | 官方 `J^` 明寫 `ipa ʝ`，但為了與 `ç→xj` 清濁配套改用 `Q+j`（`x↔Q` 正是 `voicingswitch` 對）。實測 `Qj` −22 dB / 578 Hz，與官方 `J^` 響度相當 |
| `ʁ` | `Q"` | 作者原表給 `g"`，但 phsource **沒有** `phoneme g"`；`phoneme Q"` 官方明寫 `ipa ʁ`（清音搭檔 `X`=χ）。實測 `g"` −41 dB / 532 Hz（又悶又弱），`Q"` −22 dB / 639 Hz |
| `ˤ` | `?\` | 咽化用咽擦音近似 |
| `c` `cʰ` `ç` `ɟ` | `kj` `khj` `xj` `gj` | 使用者聽感：分不出 c/cʰ/ç。實測聲母段峰值 —— `c` −49 dB、`C` −48 dB（元音 −13 dB 作標尺），幾乎無聲；`kj` −45 dB（另有 j 過渡）、`xj` −36 dB、`gj` −30 dB。故改用資料完整的 `k`/`x`/`g` + `j` |

### 鼻化

引擎把 `~` 當**可疊加的鼻化特徵** —— 任何元音加 `~` 都生效：

```
a  (25174 樣本)  vs  a~  (24087)  → 不同 ✓
ee (24095)       vs  ee~ (24809)  → 不同 ✓   （ee~ 不在音素名列表裏也生效）
A. (25174)       vs  A.~ (24467)  → 不同 ✓
```

所以預組合字符（`ã` U+00E3）與組合記號（U+0303）都拆成「基字符 + U+0303」處理：

```
ã → a~     ẽ → e~     ĩ → i~     õ → o~     ũ → u~     ỹ → y~
ɑ̃ → A.~   ɛ̃ → E~    ɔ̃ → O~    œ̃ → W~    æ̃ → &~
```

### 已知限制

* **`θ` `ð` 聽起來不像英語 th** —— 實爲齒化的 s / z。使用者明確指出過。
* **`ɾ`（閃音）與 `r`（顫音）共用同一音素名**，引擎分不開。
* **`ʏ` 與 `ø` 共用 `Y`**，同樣分不開。
* **仍未映射 6 個**：`ʙ ɞ ɶ ʜ ʢ ɘ`（`ɜ` 用長音補上、`ɟ` 改用 `g`+`j`，都已不在名單裏）。
  `ʙ` 是與既有項碰撞後撤除的（`ʙ→b\`` 撞 `ɓ`），其餘試聽後放棄。
* **`c` `cʰ` `ç` 用「軟顎音 + j」實現**（`kj` `khj` `xj`，`ɟ` 用 `gj`）——
  `c`／`C` 的分段實測確實弱：`c` 的爆破只有 10ms、峰值僅元音的 0.15（`s` 是 110ms／0.34）；
  代價是部位略偏軟顎、多一個 `j` 過渡。
* **這份 `.data` 是作者自訂編譯的，而且沒有被裁剪**（2026-10 實測）：

  | 檔案 | 本包 | Debian 1.50 | Debian 1.51 | Debian 1.52 |
  |---|---|---|---|---|
  | `phontab` | **104 850 B** | 50 136 | 55 900 | 58 652 |
  | `phonindex` | **44 114 B** | 35 252 | 39 068 | 43 316 |
  | `phondata` | **567 340 B** | 539 896 | 551 064 | 554 740 |

  多出來的是編進去的 `ipa` 表與烘焙的 `wide80` 變體（官方任何一版都沒有名爲 `ipa` 的音素表）。
  逐個合成 223 個音素名，**全部都能出聲** —— 早先「`phondata` 只有官方 5%」的說法是誤判。
  真正的限制是**這份 data 與 wasm 互鎖**：表條目佈局不同（本包約 832 B/表，官方約 430–450 B/表），
  換任何官方／Debian 的 data 都會錯位，取不到樣本。
* **`/y/` 是多數表中才有的音素，`ipa` 表與其父表 `base1` 都沒有** ——
  靠 espeak 的「跨表回退」取得，元音本身正常，但**與韻尾相接時過渡缺失**：
  `yp` `yt` `yk` 只有 149ms（同一韻腹帶鼻音尾是 226ms、帶 `-j` 是 282ms），
  尾段高頻只有 5–6%，而原生音素 `ik` 是 16–21%。
  **已用映射繞開**：配 `p t k ʔ j` 時改用 `yi`（見 `OVERRIDES` 的 `/y/ + 韻尾` 一組），
  尾段高頻回到 15–27%。**`ya` `yi` `yen` `yɑŋ` 這些不帶韻尾的場合不動** ——
  沒有韻尾相接時 `y` 本身是正常的。
  > 這是引擎資料層面的限制，**網站上有相同問題** ——
  > `ipa` 表是作者編譯進 `espeakng.worker.data` 的，換不掉。

> **本包不判斷「能不能發音」，那只能靠人耳試聽。**
> `tools/verify-table.mjs` 只做結構覈對。

### 長文本 OOM 的三個根因（都已修）

三個原因**層層疊加**，任何一個都能讓長文本失敗；修掉前兩個之後
第三個還在，所以先前一直沒能根治。

#### ① JS 定時器泄漏

`synth()` 原先收尾掛的是 `setTimeout(() => finish(false), 30000)`，**從不清除**。
每次合成都留下一個 30 秒的待決定時器，而閉包抓着這次合成的全部音頻
（每字約 100 KB）。**1000 字 ≈ 1000 個定時器 × 100 KB ≈ 100 MB 被扣住半分鐘**。

修法：定時器存 id、`finish` 時 `clearTimeout`，組完結果後把 `chunks` 置空。

#### ② 每次合成都 `new` 一個 worker / 重設 `set_voice`

`speak.mjs` 原先每次 `_synthRaw` 都 `new M.eSpeakNGWorker()` 再 `delete()`，
而 `set_voice` 會**重新加載整個語音數據**。實測 300 次合成：

```
每次 new worker          1.9s   RSS +11 MB   ← 慢 9.5 倍
復用 worker，每字重設      0.2s   RSS  +4 MB   ← 原瀏覽器做法
復用 worker，設定只下一次  0.2s   RSS  +1 MB   ← 現在
```

修法：整個 Speaker / 頁面共用一個 worker，設置**只在變化時**才下發。

#### ③ WASM 堆只有 16 MB，且**不允許增長** ★ 最根本

這是真正卡死的那一個。實測跑到約兩千次合成後：

```
Aborted(OOM). Build with -sASSERTIONS for more info.
    at abortOnCannotGrowMemory
    at _emscripten_resize_heap
```

堆一直停在 16.0 MB，分配不出來就 `abort`，**之後引擎徹底啞掉 ——
不報錯，只是再也沒有輸出**。這一點極容易誤判成「跑得好好的」，
我第一版測量就是這麼被騙的（沒校驗「真的收到了音頻」，
把空轉當成了成功）。

**注意 `new eSpeakNGWorker()` 不能重置堆** —— 只有重建整個 Module 才行。
瀏覽器裏就是重建 Worker。所以長文本**每 400 字換一個引擎**：

```js
if (done % REBUILD_EVERY === 0) { await rebuildEngine(); }
```

代價是每次重建約 1–2 秒（重新載入語音數據）。3387 字 → 8 次重建。

**實測（〈哀江南賦并序〉3387 字，`test-readings-io.mjs`）**：

```
✓ 合成量足夠大        3385 次
✓ 引擎被定期重建      重建 8 次（3387 字 ÷ 400）
✓ 朗讀完成            合計 3385 字成功、2 字失敗，耗時 50.2s
```

### 朗讀任務不能並行

早先停止用的是布爾 `stopRequested`，但有個問題：開始新朗讀時把它設回 `false`，
**上一次的循環也會看到 `false` 而繼續跑** —— 兩次朗讀同時合成，日誌交錯、音頻亂接。

改用**單調遞增的代號** `speakGen`：每次開新任務就 `++`，
舊循環發現自己的代號過期就自己退出（`test-longtext.mjs` 第 ⑥ 組守着）。

提取腳本（`tools/extract-*.mjs`）的註釋裏記錄了三個踩過的坑：
`\s` 會跨行匹配、`tshet-uinh` 只認 58 個平聲韻目（`曷` 要寫成 `寒`）、
開合中立韻（如江韻）不能帶「呼」。

## 九、版本

**v1** — 當前版本。三個頁面均已標註。

已完成：

* 三種輸入模式（推導器 / 字表 / 直接 IPA）
* 推導器四變數完整支援、設定項自動渲染（含枚舉下拉框）
* 多音字交互（藍色、點擊切換、逐音試聽、記憶選擇）
* 括號注音固定讀音、自動補全「類」
* **借字語法 `字<他字>`**（用他字的音韻地位，標紅，多音可選）
* 類推（補充字表 + 異體字表）、簡化字
* 五色狀態標記
* 標點與**行內空格**作停頓（微／短／長三級）、空行分段、單段朗讀
* **txt 匯入／匯出**（帶括號注音，可完整復現讀音）
* **點任何字看全部音韻地位**；多音的才可點選，選完寫回原文
* **引擎每 400 字重建**（繞過 16 MB WASM 堆上限）
* 對照表增補 21 條、覆蓋 16 條、鼻化處理
* **兩個專門目錄**：`texts/` 與 `derivers/`，頁面下拉框直接讀、可直接覆蓋存回
* 16 套測試（約 480 項斷言），含 3387 字長文本 OOM 測試
